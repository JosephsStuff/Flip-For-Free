Flip for Free API

Everything you can see in Flip for Free, you can read and change from a script, a spreadsheet or Claude. The API runs inside your own copy, on your computer or your own server: nobody else has your data.

Getting started

  1. Create a key. In Flip for Free go to Settings → API keys, name the key (for example "Spreadsheet") and copy it. It starts with flip_ and is only shown once. Delete it there to stop it working.
  2. Find your address. On your computer it's https://localhost:8765. On a server it's your Tailscale address, such as https://flip.your-tailnet.ts.net.
  3. Make a request. Send the key as a bearer token. Your own copy uses a self-signed certificate, hence -k (curl) or verify=False (Python) on localhost; a Tailscale address has a real certificate. 
    export FLIP_KEY=flip_your_key_here
curl -k https://localhost:8765/api/v1/summary?period=30d -H "Authorization: Bearer $FLIP_KEY"

Conventions

TopicHow it works
Base path/api/v1. GET /api/v1 lists every endpoint as JSON.
MoneyPounds (GBP) as numbers, e.g. 12.5. CardTrader and Shopify sales in other currencies are converted with the European Central Bank's daily rate.
DatesYYYY-MM-DD. Timestamps in responses are ISO 8601 in UTC.
Periods?period= today, 7d, 30d, month, last_month, 90d, ytd, fy (financial year), all, custom with start and end, or a saved range r:<id>.
ErrorsA JSON body {"error": "…"} with the HTTP status: 400 bad input, 401 missing or wrong key, 404 not found, 409 would change a filed tax year.
Filed tax yearsChanges that would alter a tax year you've marked as filed are refused with 409 unless the body includes "confirm_closed": true.
WritesSend JSON with Content-Type: application/json. PATCH changes only the fields you send.

Claude connector

Flip for Free also runs a Model Context Protocol (MCP) server, so Claude can use the same API with plain English: "I sold a Zara coat on Vinted for £28 yesterday" or "which sales are missing a cost?".

  1. Create an API key in Settings → API keys (name it "Claude desktop").
  2. Install the connector's library once, in the Flip for Free folder: pip install -r requirements.txt
  3. In the Claude desktop app open Settings → Developer → Edit Config and add (with your own folder and key): 
    {
  "mcpServers": {
    "flip-for-free": {
      "command": "python",
      "args": ["C:\Users\you\flip-for-free\mcp_server.py"],
      "env": { "FLIP_URL": "https://localhost:8765", "FLIP_API_KEY": "flip_your_key_here" }
    }
  }
}
  4. Restart Claude. The tools below appear while Flip for Free is running.
ToolWhat it does
get_summaryProfit summary: sales, money made after eBay fees and your packing costs, cost of goods, profit, and how many sales are missing a cost. period: today, 7d, 30d, month, last_month, 90d, ytd, fy, all, or custom (with start/end as YYYY-MM-DD).
get_time_to_sellHow long things take to sell. Single-quantity listings: average and median days from first listed (across relists) to sold, a spread, and what's been listed longest. Multi-quantity listings: how often one sells ("one every N days"), units per week, stock left and roughly when each will sell out.
get_tax_summaryUK Self Assessment (SA103S) figures for a tax year (year = the year it starts, e.g. 2026 for 2026/27), plus data checks to fix before filing. basis: cash or accrual.
list_notificationsRecent alerts: new sales (with storage location), problems eBay charged for, automation results. kind: sale, issue or automation.
start_syncPull the latest orders, fees and listings from eBay now.
list_salesSales with the full breakdown (what the buyer paid, eBay deductions, your costs, profit). Use missing_cost_only=True to find sales that still need what you paid.
update_sale_costsSet your costs on one sale. cost = what you paid for the item(s) in this sale. postage_cost only for postage bought outside eBay. Only the fields you pass are changed.
record_saleRecord a sale made outside eBay (Vinted, Facebook Marketplace, Depop, Etsy, car boot, in person...). Link it to an inventory item with item_id so its cost and bulk buy are used. Don't use for eBay sales: those sync automatically. update_ebay=True also lowers the item's listings on eBay, CardTrader and Shopify (or ends them if none are left) so it can't sell twice: only set it when the user asks for that.
list_itemsInventory items. status: instock (listed + not listed), listed, unlisted, sold or all.
get_itemOne inventory item with its eBay listings, sales and timeline.
add_itemsAdd stock you've bought. One item is created per title, all sharing the other details. For things from a bulk buy, pass bulk_buy_id and leave cost_each empty (they share the lot's cost), unless fixed_cost_in_bulk=True for a valuable item with its own cost.
update_itemChange an inventory item. Only fields you pass change. link_listing = an eBay item ID to attach.
write_off_itemWrite an item off as lost, damaged or donated (its cost then shows on the P&L).
list_listingsThe user's eBay listings (synced). status: active, ended, sold or all.
list_bulk_buysBulk buys (job lots, binders, car boot hauls) with cost, money made back, profit and ROI.
create_bulk_buyCreate a bulk buy. item_count = how many items were in the lot (used to split the cost). split_method: even, or price (weighted by each item's price). item_titles logs its items now.
update_bulk_buyChange a bulk buy. Only fields you pass change.
link_listings_to_bulk_buyPut existing eBay listings (by eBay item ID) into a bulk buy; their past and future sales count towards it.
list_expensesBusiness expenses for a UK tax year (year it starts, e.g. 2026 = 6 Apr 2026 – 5 Apr 2027).
add_expenseLog a business expense. category: stock, travel, wages, premises, repairs, professional, finance, office (postage, packaging, phone, stationery), software, advertising, platform, equipment, other. Don't log eBay fees or eBay postage labels: those sync automatically.
add_mileageLog a business journey (sourcing trip, collecting a lot, post office run). return_trip doubles the miles.

Profit for the last 30 days.

curl -k -X GET "https://localhost:8765/api/v1/summary?period=30d" \

print(r.json())
const r = await fetch("https://localhost:8765/api/v1/summary?period=30d", {

});

PATCH

/api/v1/sales/<line_item_id>

Set your costs on a sale: cost, postage_cost, packaging_cost, handling_cost, other_cost, bulk_buy_id (null to remove), notes.

curl -k -X PATCH "https://localhost:8765/api/v1/sales/S-demo5" \
  -H "Authorization: Bearer $FLIP_KEY" \
  -H "Content-Type: application/json" \
  -d '{"cost": 4.5, "packaging_cost": 0.3}'
import os, requests

r = requests.patch(
    "https://localhost:8765/api/v1/sales/S-demo5",
    headers={"Authorization": "Bearer " + os.environ["FLIP_KEY"]},
    json={"cost": 4.5, "packaging_cost": 0.3},
    verify=False,  # your own copy uses a self-signed certificate
)
print(r.json())
const r = await fetch("https://localhost:8765/api/v1/sales/S-demo5", {
  method: "PATCH",
  headers: { Authorization: `Bearer ${process.env.FLIP_KEY}`, "Content-Type": "application/json" },
  body: JSON.stringify({"cost": 4.5, "packaging_cost": 0.3}),
});
console.log(await r.json());
