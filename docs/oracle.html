Create the free server in 3 steps

1

Open an Oracle Cloud account

Sign up at cloud.oracle.com/free and pick UK South (London) as your home region. It can't change later.

2

Create an Ubuntu server

First Networking, Virtual cloud networks, Actions, Start VCN Wizard, Create VCN with Internet Connectivity. Then Compute, Instances, Create instance: pick that network's public subnet and keep Automatically assign public IPv4 address on. Download the SSH key Oracle makes for you.

Flip for Free server commands

Updates, sync timing and database downloads live in Flip for Free's Settings. The server needs a command only for these.

  • Update to a new versionSettings, Updates
  • Set how often it syncsevery 5 min to 24 h
  • Download your databaseSettings, Your data
  • Copy backups to Google Driverclone remote gdrive
On the server
# is it running? live log?
sudo systemctl status flip
journalctl -u flip -f

# back up now
bash ~/flip-for-free/deploy/backup.sh

# restore a backup
sudo systemctl stop flip
gunzip -c ~/flip-data/backups/flip-DATE.db.gz > ~/flip-data/ebay_profit_tracker.db
sudo systemctl start flip

Questions

Anything else is answered in the written guide on GitHub.

Can Oracle delete my free server?

Oracle may reclaim one that sits mostly idle for 7 days. Keep the Google Drive backup on, and log in to the console now and then: unused accounts are suspended after 30 days.

Can I keep Flip for Free on my PC too?

No. Close the PC copy once the server runs, or both would relist and promote the same listings.

Who can reach the Flip for Free server?

Only devices signed in to your Tailscale account. Flip for Free listens on the server itself, and you can close port 22 once Tailscale SSH works.

Does Flip for Free use anyone else's account?

No. Each person uses their own eBay keys, server and Tailscale account.
