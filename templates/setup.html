    Sign-in uses eBay's own login page (OAuth). The tool needs an eBay developer app — it's free and takes about 10 minutes.

    How to get these keys
    1. Sign in at developer.ebay.com/my/keys (Application Keysets) and create a Production keyset.
      If it says the keyset is disabled, click through the Marketplace account deletion notice and choose the exemption option (you don't store other people's data). The keyset won't work until you do.
    2. Copy the three values from the Production box into the fields with the same names below: App ID (Client ID), Dev ID and Cert ID (Client Secret) (click the eye icon to reveal it).
    3. In the Production box, under App ID, click User Tokens. Under Get a Token from eBay via Your Application, click Add eBay Redirect URL. eBay first asks you to confirm your legal address, then you can fill in:
      • Display Title: anything, e.g. Flip for Free
      • Your privacy policy URL: any https page of yours (required by eBay)
      • Your auth accepted URL: {{ callback }}
        If eBay won't save a localhost address, use the relay page instead (see the README: "If eBay won't accept localhost"). It sends you straight back here, so sign-in stays automatic.
      • Your auth declined URL: the same as the accepted URL
      • Tick OAuth Enabled, then Save.
    4. Copy the value in the RuName (eBay Redirect URL name) column. It looks like Your_Name-YourApp-PRD-abcdefgh.

    Your keys and eBay sign-in token are saved inside the database file so other devices pointed at it work straight away. Keep that folder private.
